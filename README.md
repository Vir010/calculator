# Калькулятор стоимости ремонта квартиры

Одностраничный калькулятор, который считает предварительную стоимость ремонта
по типу работ, площади, срочности и выезду мастера, с пояснением расчёта.

## Стек

- HTML5 (семантическая вёрстка)
- CSS3 (Grid, Flexbox, CSS-переменные, медиазапросы)
- JavaScript (ES6+, работа с формой и DOM, `Intl.NumberFormat`)

## Деплой

[Открыть сайт](https://vir010.github.io/calculator/)

## Как запустить локально

1. Склонировать репозиторий:

   ```
   git clone https://github.com/Vir010/calculator.git
   ```

2. Открыть `index.html` в браузере или запустить Live Server в VS Code.

## Функциональность

- Форма из четырёх полей: тип работ, площадь, срочность, выезд мастера.
- Расчёт стоимости: базовая ставка × площадь, коэффициент срочности, надбавка за выезд.
- Вывод итоговой суммы и построчной расшифровки расчёта.
- Валидация поля «Площадь» с сообщением об ошибке под полем.
- Адаптив: две колонки на десктопе, одна — на планшете и мобильном.
